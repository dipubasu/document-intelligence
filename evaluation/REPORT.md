## Limits of this measurement

- The dataset is synthetic. Every file was generated by evaluation/generateDataset.js. These are not real invoices.
- The three images are generated from text (SVG turned into PNG/JPG with some blur and rotation). They are not real photos or scans, so the OCR numbers say little about real scans.
- Documents were generated from a few layouts. Real documents are more varied, so real accuracy can be lower.
- The sample is small (24 documents to extract). One wrong field changes the percentages noticeably.
- This is a single run. LLM answers can differ between runs, so a second run can give slightly different numbers.
- A failure caused by an LLM rate limit counts as a failure here. The error message column shows the cause.
- Scanned PDFs, TIFF and old .xls files are not supported and are not in this dataset.
- The 1000-page case and semantic search quality are not part of this report.
